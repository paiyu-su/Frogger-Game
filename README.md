\# Frogger Game（青蛙過馬路）



\## 專案簡介



本專案使用 C++ 開發一款文字介面的青蛙過馬路（Frogger）遊戲。玩家需要控制青蛙穿越馬路，避開移動中的車輛並成功抵達終點。為了增加遊戲的趣味性與挑戰性，本專案額外加入了難度系統、金幣系統以及紅綠燈系統。



本專案採用物件導向程式設計（Object-Oriented Programming, OOP）與模組化設計方式開發，將遊戲功能拆分為多個類別，提升程式的可讀性、維護性與擴充性。



\---



\# 遊戲功能



\## 1. 難度系統



遊戲開始時可選擇不同難度：



\### Easy



\* 生命值：5

\* 車輛數量：4

\* 遊戲速度：較慢



\### Normal



\* 生命值：3

\* 車輛數量：6

\* 遊戲速度：一般



\### Hard



\* 生命值：2

\* 車輛數量：8

\* 遊戲速度：較快



透過不同參數設定，提高遊戲挑戰性與可玩性。



\---



\## 2. 金幣系統



地圖中會隨機產生金幣（$）。



玩家取得金幣後：



\* 分數增加 50 分

\* 金幣重新隨機生成



此功能增加了玩家探索地圖與收集資源的樂趣。



\---



\## 3. 紅綠燈系統



遊戲中加入交通號誌機制：



\### GREEN



車輛正常移動



\### RED



車輛停止移動



玩家可利用紅燈期間安全通過馬路，增加遊戲策略性與真實感。



\---



\## 4. 關卡系統



當玩家成功抵達終點：



\* 分數增加 100 分

\* 關卡等級提升

\* 遊戲速度加快



使遊戲難度隨著關卡逐漸提升。
